ตัวเลขในแต่ละข้อเปลี่ยนตามตัวกรอง

  1. ลด X Flag ก่อน เพราะเป็นก้อนใหญ่ที่สุด X Flag คิดเป็น — ของเอกสารไม่สมบูรณ์ และสาเหตุอันดับหนึ่งคือ — (—) → ให้ระบบขายบังคับแนบเอกสารหลักก่อนกดส่ง (hard stop) และเตือนหน้าร้านทันทีที่เอกสารถูก Flag
  2. ทำ checklist ตามประเภทลูกค้า สาเหตุย่อยที่พบบ่อยสุด 3 อันดับคือ —, — และ — → แยก checklist คนไทย / ต่างชาติ (Passport, Work Permit, VISA อายุเหลือ ≥ 6 เดือน) / นิติบุคคล / ผู้เยาว์ และใส่ใบสัญญาบริการพยากรณ์เลขหมายเป็นเอกสารบังคับสำหรับเบอร์มงคล
  3. โฟกัสภาคและสาขาที่ต่ำสุด — มี % สมบูรณ์ — เทียบภาพรวม — และมีสาขาที่ % สมบูรณ์ต่ำกว่า 80% อยู่ — จาก — สาขาที่มีเอกสาร 30 ฉบับขึ้นไป → ส่งรายชื่อสาขาในตารางด้านล่างให้ Area Manager ทำ coaching รายสัปดาห์ และติดตาม % สมบูรณ์รายสาขา
  4. ดู Channel ที่ต่างกันมาก — มี % สมบูรณ์ — ขณะที่ — อยู่ที่ — → ทบทวนขั้นตอนการรับเอกสารของ Channel ที่ต่ำ และนำวิธีของ Channel ที่ดีที่สุดไปใช้
  5. ตรวจคุณภาพ Smart Doc เอกสารที่ทำ Smart Doc สมบูรณ์ — เทียบกับที่ไม่ได้ทำ — → ถ้า Smart Doc ต่ำกว่า ให้ตรวจความชัดของภาพสแกนและการแนบไฟล์ครบหน้าในขั้นตอน Upload
  6. ตั้ง SLA การตรวจ เอกสาร — ใช้เวลาเกิน 7 วันนับจากวันทำรายการ → ตั้งเป้าตรวจเสร็จภายใน 7 วัน และเร่งการส่งซองเอกสารจากหน้าร้าน โดยเฉพาะรายการประเภทนำส่งแบบ "ปรับปรุง"
